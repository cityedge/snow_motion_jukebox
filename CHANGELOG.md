# Changelog

All notable public releases of Snow / Motion are documented here.

## 1.1.0 — 2026-09-02

- Improved lead snowboarder flights around closely spaced terrain features so they land naturally instead of dropping vertically.
- Added restrained midday ground-side ambient fill so trees and rocks retain colour and form without making snow glare.

## 1.0.0 — 2026-09-01

- Added a persistent master-volume control to the main menu and made the FPS overlay opt-in by default.
- Widened distant scenery, anchored far forests to mountain ridges, and framed open vistas to prevent exposed background edges.
- Added complete release documentation and one reproducible repository archive with a conventional top-level release folder containing source, lockfile, curated runtime assets, tests, and the GitHub Pages build.
- Added eight bundled songs with track-specific environment and weather direction.
- Added authored and fully randomized stage modes.
- Added local music playback with optional matching SRT subtitles and a 10-minute safety limit.
- Added procedural courses, jumps, tunnels, obstacles, snow, fog, wind, night lighting, and lead snowboarders.
- Added Japanese and English interfaces, keyboard-accessible menus, pause flow, and next-track progression.
- Added textured snow, trees, rocks, and tunnel entrances.
- Added deterministic debug seeds, stage parameter display, FPS and CPU-headroom displays, and smoke-test coverage.
- Prepared a relative-path static build for GitHub Pages.
